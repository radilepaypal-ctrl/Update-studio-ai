# Timeline Visualizer 1.3.0

## English

Your finished travel videos now have a home. The new **Creations** library keeps
videos available after you leave the app or create another one. It shows a thumbnail,
title, Timeline period, duration, and creation date, with quick Watch and Share actions.

Videos remain in the folder you chose. Timeline Visualizer stores only a small local
index and thumbnail, and requests lasting access only to the files you selected. Use
**Add videos** to include one or several MP4s created before this update.

If a video is moved or deleted outside the app, it is clearly marked unavailable.
**Remove from list** keeps the MP4, while **Delete video** is a separate confirmed
action that removes the actual file when supported by its storage location.

The bottom of the app now includes **Check for updates on GitHub**, which opens the
latest official release. Location processing has not changed: valid small movements
continue to be included in the route.

### Install or update

Download `TimelineVisualizer-v1.3.0.apk` below and open it on an Android 8.0 or newer
phone. Existing users can install it directly over the previous release.

If Android blocks the installation, open the prompt's **Settings**, allow the browser
or file app you used to **Install unknown apps**, then return and install the APK.
You may turn that permission off again afterward. Only download the APK from this
GitHub repository.

## 한국어

완성된 여행 영상을 이제 앱에서 계속 관리할 수 있습니다. 새로운 **만든 영상** 목록은
앱을 나가거나 다른 영상을 만든 뒤에도 이전 영상을 보여 줍니다. 미리보기 이미지, 제목,
타임라인 기간, 영상 길이, 만든 날짜를 확인하고 바로 보거나 공유할 수 있습니다.

영상은 사용자가 선택한 폴더에 그대로 보관됩니다. 앱에는 작은 목록 정보와 미리보기
이미지만 저장하고, 사용자가 선택한 파일에만 지속적인 접근 권한을 요청합니다. 업데이트
전에 만든 MP4도 **영상 추가**로 한 번에 여러 개 가져올 수 있습니다.

앱 밖에서 영상을 옮기거나 삭제하면 파일을 찾을 수 없다고 표시합니다. **목록에서 제거**는
MP4를 그대로 두며, **영상 파일 삭제**는 별도의 확인을 거쳐 저장 위치가 허용하는 경우에만
실제 파일을 삭제합니다.

앱 아래쪽의 **GitHub에서 업데이트 확인**을 누르면 공식 최신 릴리스를 열 수 있습니다.
위치 처리 방식은 바꾸지 않았으며, 유효한 짧은 이동도 계속 경로에 포함됩니다.
