# Timeline Visualizer 2.2.9

After the first successful Timeline JSON import, the app keeps a private preprocessed
copy so the remembered file opens much faster later. Selecting the file again refreshes
the copy. Missing, changed, or damaged cache data safely falls back to the original JSON.
Timeline data remains on the device.
