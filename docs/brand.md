# Timeline Visualizer identity

Timeline Visualizer uses a pin-and-route mark, pale surfaces, dark plum text, and
a vivid magenta accent. The identity must remain visually independent from Google.

## Palette

| Role | Color |
| --- | --- |
| Logo and large brand elements | `#E90064` |
| Interactive controls and links | `#D0005A` |
| Main surface | `#FFF8FA` |
| Container surface | `#F7EEF1` |
| Primary text | `#24191D` |

Use semantic Android color resources instead of hard-coded layout colors. Version
1.9 uses the Material 3 light theme only.

## Mark

The canonical vector is [`images/timeline-visualizer-mark.svg`](images/timeline-visualizer-mark.svg).
Keep clear space around the pin and route. At small sizes, use the mark without a
wordmark. Android themed icons use the monochrome layer so the launcher controls
the final color.

Do not add Google colors, the Google Maps pin shape, a Google wordmark, or any copy
that implies affiliation. The app title is **Timeline Visualizer**. The phrase
“for Google Maps Timeline” is allowed only in descriptions and instructions.

The project does not have a website, so it does not ship a favicon.
