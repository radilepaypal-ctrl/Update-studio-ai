# タイムライン可視化 1.8.1

- 機種変更や端末の初期化後に、暗号化された Google マップのタイムラインを
  復元するためのガイドをアプリから確認できます。
- Google マップでの復元から JSON の書き出し、タイムライン可視化での読み込み
  までを、Google アカウントへのアクセスを追加せずに案内します。
- アプリの表示文と英語、韓国語、日本語の説明をより分かりやすく整えました。
- 経路の再生時間を10、15、20、30、45、60秒から選べます。
