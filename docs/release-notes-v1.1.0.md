# Timeline Visualizer 1.1.0

## English

This release makes important long-distance trips visible instead of jumping from
one endpoint to the other. Sparse flights are now interpolated along a smooth
great-circle route, with the camera following the moving position and preparing
map tiles ahead of it.

You can also select a start and end month, use an automatic year-and-name title,
open clear Timeline export instructions from the app, replay from the beginning,
and share the latest MP4 directly to social or messaging apps.

### Install

Download `TimelineVisualizer-v1.1.0.apk` below and open it on an Android 8.0 or
newer phone. If Android blocks the installation, allow the browser or file manager
you used to **Install unknown apps**, complete the installation, then turn that
permission off again.

Timeline data is exported from **Phone Settings → Location → Location services →
Timeline → Export Timeline data**. The app does not require Google sign-in or
location permission.

Thanks to [@keenranger](https://github.com/keenranger) for contributing iOS
Timeline export support in [#2](https://github.com/mahlernim/google-timeline-visualizer/pull/2).

## 한국어

장거리 이동이 출발지에서 목적지로 갑자기 건너뛰던 문제를 해결했습니다. 비행처럼
중간 위치가 드문 구간을 부드러운 대권 경로로 보간하고, 카메라와 배경 지도가 이동
위치를 미리 따라가도록 개선했습니다.

시작 월과 종료 월 선택, 연도와 이름을 이용한 자동 제목, 앱 안의 타임라인 내보내기
안내, 처음부터 다시 재생, 최근 MP4를 SNS·메신저로 공유하는 기능도 추가했습니다.

### 설치

아래에서 `TimelineVisualizer-v1.1.0.apk`를 다운로드해 Android 8.0 이상 휴대전화에서
여세요. 설치가 차단되면 사용한 브라우저 또는 파일 앱의 **출처를 알 수 없는 앱 설치**를
잠시 허용하고, 설치가 끝난 뒤 권한을 다시 꺼도 됩니다.

타임라인 데이터는 **휴대전화 설정 → 위치 → 위치 서비스 → 타임라인 → 타임라인 데이터
내보내기**에서 저장합니다. Google 로그인과 위치 권한은 필요하지 않습니다.

iOS 타임라인 내보내기 지원을 기여한
[@keenranger](https://github.com/keenranger) 님과
[#2](https://github.com/mahlernim/google-timeline-visualizer/pull/2)에 감사드립니다.
