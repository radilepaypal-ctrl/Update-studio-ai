# Timeline Visualizer terminology

This glossary is the canonical source for user-facing product terminology. Use
the localized equivalent in headings and keep button labels short enough to fit
on one line at 360dp.

| Concept | English | Korean | Japanese |
| --- | --- | --- | --- |
| Google source | Timeline file | 타임라인 파일 | タイムライン ファイル |
| Drawn travel path | Journey | 이동 경로 | 移動経路 |
| Generated MP4 | Video | 영상 | 動画 |
| User selection | Selected period | 선택 기간 | 選択期間 |
| Final still | Journey overview | 전체 이동 경로 | 移動経路の全体図 |

## Usage rules

- Use **Export Timeline data** only for the action performed in Google.
- Use **Create video** for output produced by Timeline Visualizer.
- Journey refers only to the drawn animated path and its final overview.
- Never call the selected date range a journey.
- Use JSON only for the usual filename `Timeline.json` or when documenting the file format.
- Preserve user-defined titles and saved title templates.
- Put nouns in section headings. Use short verbs in buttons and complete phrases in accessibility labels.

## Standard states

- Opening file
- Reading Timeline file
- Preparing journey
- Preparing map
- Creating video
- Finishing video
- Video saved
- Video creation cancelled
- Timeline file unavailable
- Video file unavailable
