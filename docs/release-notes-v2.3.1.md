# Timeline Visualizer 2.3.1

Save the five camera and aspect-ratio choices from Video defaults as a reusable
preset. Presets appear directly in Create video, apply only to the current draft,
and become the default only when you explicitly choose Set as default. Rename,
delete, and share saved presets from the same flow.

Compact HTTPS preset links contain only those five settings. They never contain
Timeline data, locations, dates, owner names, titles, filenames, or resolution.
Opening a link shows every value for confirmation before anything is applied or
saved.
