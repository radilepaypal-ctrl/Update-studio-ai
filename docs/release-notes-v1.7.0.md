# Timeline Visualizer 1.7.0

## Faster, clearer yearly videos

Older travel now fades naturally behind the moving position marker. The app keeps
the recent journey clear without repeatedly drawing every detailed location in a
full year, making dense Timelines more efficient to turn into video.

Each video now ends with a polished 1.5-second overview: the map smoothly zooms out,
the complete journey appears, and the finished route remains on screen for a final
half second. New 45-second and 75-second journey options provide more pacing choices.

The selected journey duration does not include the ending. For example, a
30-second journey produces a video approximately 31.5 seconds long.

# 타임라인 비주얼라이저 1.7.0

## 더 빠르고 깔끔해진 연간 영상

이제 오래된 이동 경로는 위치 마커 뒤에서 자연스럽게 사라집니다. 최근 경로는 선명하게
유지하면서 한 해의 모든 상세 위치를 매 프레임 다시 그리지 않아, 위치가 많은 타임라인도
더 효율적으로 영상으로 만들 수 있습니다.

영상 마지막에는 1.5초 길이의 전체 경로 화면이 추가됩니다. 지도가 부드럽게 축소되면서
전체 이동 경로가 나타나고, 완성된 지도를 마지막 0.5초 동안 보여 줍니다. 이동 속도를
더 세밀하게 선택할 수 있도록 45초와 75초 옵션도 추가했습니다.

선택한 이동 재생 길이에는 마지막 화면이 포함되지 않습니다. 예를 들어 30초를 선택하면
완성 영상은 약 31.5초입니다.
