# Timeline Visualizer 1.9.0

Version 1.9 makes video creation more focused and removes destination decisions
from the common Android 10 and later workflow.

- Open the Videos library first and create a video in a separate New video screen.
- See live point and approximate-distance feedback under Selected period.
- Continue rendering after returning to Videos, with visible progress and Cancel.
- Save completed MP4 files automatically to `Movies/Timeline Visualizer` on Android 10 and later.
- Use Save as to copy a completed video without rendering it again.
- Save the optional Journey overview only when requested.
- Use consistent Timeline file, Journey, Video, Selected period, and Journey overview terminology.
- Refresh the light visual system, semantic colors, logo source, and themed launcher icon.
- Keep existing video records, titles, templates, pending exports, and remembered Timeline access compatible.

Android 8 and 9 continue to use the system Save As picker and require no new storage permission.
